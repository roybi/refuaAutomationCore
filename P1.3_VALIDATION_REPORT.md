## Known Limitations and Future Enhancements

### Current Limitations (By Design)

1. **Device Support (P2.2)**
   - Script accepts `--device` flag
   - Only "desktop" functional in P1.3
   - iPhone/Android require P2.2 (DeviceManager)

2. **Browser Support**
   - Only Chromium (Firefox, WebKit, Safari in future)
   - Session file: `auth_state_{env}_chromium_latest.json`

3. **Manual Capture**
   - User must run script manually once per environment
   - No automatic refresh mechanism (future enhancement)

### Future Enhancements (Planned)

1. **P2.2 - Multi-Device Support**
   - Session capture for iPhone/Android
   - Session files: `auth_state_{env}_{device}_latest.json`

2. **P2.4 - Automated Testing**
   - Unit tests for SessionStateManager
   - Integration tests for capture script
   - Test coverage reporting

3. **P4.2 - CI/CD Automation**
   - Automated session capture in pipeline
   - Session rotation for production
   - Secure credential storage

4. **Future - Quality of Life**
   - Auto-detect expired sessions
   - Prompt user to refresh
   - Support multiple browsers
   - Session comparison for debugging
