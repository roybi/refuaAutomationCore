KEY FEATURES
================================================================================

CAPTURE ALL BROWSERS
  Command: python scripts/capture_session.py --env test --user john.doe
  Creates: 4 session files (one per browser)
  Time: ~8-10 minutes (depends on login complexity)
  Output: Progress tracking [1/4] [2/4] [3/4] [4/4]

CAPTURE SPECIFIC BROWSER
  Command: python scripts/capture_session.py --env test --user john.doe --browser firefox
  Creates: 1 session file for firefox only
  Use: Refresh single browser, debugging, targeted capture

DOCKER VOLUME SUPPORT
  Host: docker run -v ~/.refua_sessions:/sessions myimage ...
  Container: SESSION_DIR=/sessions python scripts/capture_session.py ...
  Volumes: ~/.refua_sessions/ (host) → /sessions (container)
  Benefit: Sessions persist across container runs

GRACEFUL ERROR HANDLING
  Browser X fails: logged, continues to next browser
  Failed browsers: reported in summary
  Partial success: returns successes and failures
  User control: can retry or continue

BACKWARDS COMPATIBILITY
  Existing tests: unchanged, continue to work
  Single-browser sessions: still supported
  TEST_ENV variable: still supported
  Session file format: identical to original
  No migration needed

    TEST_ENV=test SKIP_2FA=true pytest -n auto

Per Environment:

         auth_state_test_firefox_latest.json
         auth_state_test_webkit_latest.json
         auth_state_test_safari_latest.json

  preprod/: auth_state_preprod_chromium_latest.json
            auth_state_preprod_firefox_latest.json

            auth_state_preprod_safari_latest.json

  prod/: auth_state_prod_chromium_latest.json
         auth_state_prod_firefox_latest.json
         auth_state_prod_webkit_latest.json
         auth_state_prod_safari_latest.json

File Format: JSON with cookies, localStorage, metadata, tokens
TTL: 3 days from capture time
Refresh: Re-run capture script to refresh expired sessions
